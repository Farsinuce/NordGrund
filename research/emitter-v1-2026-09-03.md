## The emitter's contract with the fork 🟢 (read at 78215bd)

- Elements: Overpass JSON shape (`elements`: node/way/relation, `nodes` as id lists, `tags`).
  IDs are u64; ours: way = 2^40 + 4·id_lokalId + ring, node = 2^41 + 2048·id_lokalId + vertex,
  relation = 2^42 + id_lokalId, entrance node = 2^43 + husnummer sequence, manhole = 2^44 +
  id_lokalId. Deterministic and disjoint from OSM ids (max 1.4e10 seen).
- `height` sets the WALL height in blocks and the roof is built above it
  (`buildings.rs:1817-1835`); `building:levels` gives levels × 4 + 2 (`:1796-1808`). So the
  emitted `height` is the roof-edge eave above the DHM ground (median over the ring's vertices,
  kept when 2–120 m): n = 18,189, median 3.6 m, p90 14.2 m. Storeys ride along as
  `building:levels` (BBR byg054, 100 % on non-sheds; sheds get 1).
- `building=*` from BBR byg021 through a closed table of every code seen in 0751 (a new code
  aborts); unkeyed footprints become `shed` (underMinimum) or `yes` (4,349 in the box, counted).
  `building:material` from byg032, `roof:material` + `roof:colour` from byg033;
  `nordgrund:residential=yes|no` for the sign rule; `nordgrund:id` for tracing.
- Entrances: the DAR access point snapped onto the outer ring (≤ 25 m) and inserted as an
  outline node with `entrance=main` + `addr:street/housenumber/postcode`. The fork already
  suppresses its preset doors and places a dark-oak door at a mapped entrance node
  (`buildings.rs:1136-1150`, `doors.rs:5-24`). The parser drops `addr:*`
  (`osm_parser.rs:46-47`); the `nordgrund` branch keeps the three keys (30 lines, unit-tested).
- Manholes: `man_made=manhole` nodes; the fork dispatches `man_made` nodes to
  `man_made.rs:525` (no manhole case yet — the §16 feature).
- Tiles: each building goes into every z11 tile its bbox touches (Arnis dedups by id); OSM
  building/building:part ways and their relations with a centroid inside the coverage box are
  removed; originals kept under `osm-original/`; `.osmbin` sidecars deleted (fail-open anyway).
