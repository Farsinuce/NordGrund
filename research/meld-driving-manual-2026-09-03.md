## 5. Grid arithmetic

**Formula** (`meld/src/coords.py:9-12 "mpd_lon = 111320 * cos(origin_lat) (one project-wide constant); block_x(lon) = floor((lon - origin_lon) * mpd_lon * scale); block_z(lat) = floor((origin_lat - lat) * mpd_lat * scale) # +Z = south"`; executable at `:66-71`). Constants `REGION_BLOCKS = 512`, `CHUNK_BLOCKS = 16`, `METERS_PER_DEG_LAT = 111_320.0` (`meld/src/constants.py:3-7`). The fork uses the identical affine in master-origin mode (`arnis/src/coordinate_system/transformation.rs:182-188 "let dx_m = (llpoint.lng() - origin_lng) * mpd_lon; let dz_m = (origin_lat - llpoint.lat()) * METERS_PER_DEG_LAT;"`; elevation grid `arnis/src/elevation/mod.rs:104-111`). Block (0,0) is the origin point; region `r.RX.RZ` = blocks `[RX*512, RX*512+512)` (`meld/src/coords.py:20-21`).

**Anchoring.** `POST /api/origin` snaps to whole 512-block regions counted from lat 0 / lon 0 at the current scale: `rdeg_lat = 512/scale/111320 = 0.004599353 deg`; `rdeg_lon = 512/scale/mpd_lon(snapped_lat)` (`meld/src/coords.py:152-159 "rdeg_lat = REGION_BLOCKS / scale / METERS_PER_DEG_LAT; slat = anchor_lat + round((lat - anchor_lat) / rdeg_lat) * rdeg_lat … rdeg_lon = REGION_BLOCKS / scale / mpd_lon(ref_lat)"`). Cell `(rx,rz)` has `south = origin_lat + rz*d_lat`, `west = origin_lon + rx*d_lon` with `d = size*512/scale` metres (`meld/src/coords.py:163-178 "blocks_per_job = size * REGION_BLOCKS … south = origin_lat + rz_idx * d_lat; west = origin_lon + rx_idx * d_lon"`); the origin is the shared corner of cells (-1,-1),(0,-1),(-1,0),(0,0); rz counts NORTH, so region offset is `(rx*size, -rz*size)` (`meld/src/coords.py:79-86 "return rx_idx * size, -rz_idx * size"`). Cell id = string `"rx,rz,size"` (`meld/src/grid.py:91`).

**Whole cells, never clipped.** A cell is planned when it overlaps the bbox at all (`meld/src/grid.py:55-56 "a cell is included when it overlaps the selection bbox at all"`; `:74-93 "if cell_east <= west or cell_west >= east: continue"`), and the runner rebuilds the full cell bbox from the key, then pads 8 chunks = 128 blocks per side and snaps to the block grid (`meld/server.py:2701-2708 "base_bbox = cell_bbox(rx, rz, size, origin[\"lat\"], origin[\"lon\"], scale_f); arnis_bbox = expand_bbox_for_seam(base_bbox, seam, origin, scale_f)"`; `meld/src/coords.py:235-243`). The halo regions are discarded at merge (`meld/src/merge.py:157-159 "continue  # seam-buffer region — discard"`); the cell owns `rx ∈ [rx*size, rx*size+size-1]`, `rz ∈ [-rz*size-size, -rz*size-1]` (`meld/src/coords.py:111-116 "rz_min = rz_off - size … rz_max = rz_off - 1"`).

## 8. Traps (silent deviations from the GOAL)

1. **Launcher replaces the pin.** Without `meld\arnis.exe`, `meld_launch.py` fetches the latest release (`meld/meld_launch.py:237-244`). Keep the file in place; never delete it while using the launcher.
2. **`bin/` precedence.** A newer `arnis.exe` in `<data>/bin` wins silently (`meld/server.py:2351-2360`); only the UI update dialog's "Update generator" button writes there (`meld/web/index.html:6180-6198`).
