## Determinism (cell `0,0,4` regenerated twice via `/api/cell/regenerate-cells`)

| comparison | region-file sha256 | `tools/world_diff.py` (blocks, biomes, block entities, heightmaps; palette order ignored) |
|---|---|---|
| run 1 → run 2 | all 16 of the cell's regions differ; the other 48 identical | 16,384 / 16,384 chunks identical (881 differ in palette order only) — run 1 read from the server-loaded copy |
| run 2 → run 3 | all 16 differ | **16,384 / 16,384 identical**, 888 palette-order-only |
| run 1 (after a server load + save) → run 3 | — | 16,384 / 16,384 identical: the 10 s boot changed no block |

So the fork is deterministic at the block level with `--seed`, and `ARNIS_FILL_BUDGET=1` (Meld sets it, `server.py:2840`); region bytes are not reproducible because chunk palettes are written in varying order. Region timestamps are a constant (2024-09-14). PRIMER §3/§4's "region files should hash identically" needs the block-level form.
